# Go Starter Template

A minimal Go project template for quick prototyping.

## Quick Start

```bash
go run main.go
```

## Project Structure

- `main.go` — Entry point
- `.vscode/` — Editor configuration (Go language server, formatting, linting)
- `scripts/` — Build and test utilities

## Editor Setup

This project includes a pre-configured Go development environment. The settings
configure the Go language server (gopls) with optimal defaults for Cloud Shell
and local development.

### Features

- Go language server integration
- Auto-completion and IntelliSense
- Code formatting on save
- Integrated debugging support

## Requirements

- Go 1.21+
- Node.js 18+ (for editor tooling)
- VS Code, Code OSS, or Cloud Shell Editor
